# 集合

集合（Collection）用来组织保存的请求，里面可以建多层文件夹。侧边栏 **Collections** 中显示所有集合。

![集合树](/screenshots/collections.png)

## 新建和保存

- 点击 **New Collection** 新建集合。
- 新请求第一次点击 **Save** 时，选择保存到哪个集合和文件夹；选中集合本身即保存在集合根目录（显示为 **(collection root)**）。对话框默认选中上次保存的位置，只有一个集合时默认选中它；也可以在对话框中点击 **New Collection** 直接新建集合。
- 在集合或文件夹上右键，**Add Request** 新建请求，**Add Folder** 新建文件夹。

## 整理

在集合树中右键打开菜单。

**集合和文件夹**：

| 操作 | 说明 |
|------|------|
| **Add Request** / **Add Folder** | 在其中新建请求或文件夹 |
| **Move Up** / **Move Down** | 仅文件夹：在同一层中上移、下移 |
| **Duplicate** | 复制，包括其中的文件夹和请求（选中后也可按 `Ctrl+D`） |
| **Rename** | 重命名 |
| **Import** / **Export** | 导入或导出，见[导入导出](./import-export) |
| **Delete** | 删除，其中的请求一起删除（选中后也可按 `Delete`） |

**请求**：

| 操作 | 说明 |
|------|------|
| **Open** | 打开 |
| **Move Up** / **Move Down** | 在同一层中上移、下移 |
| **Move to...** | 移到其他集合或文件夹，放在末尾 |
| **Duplicate** | 复制（选中后也可按 `Ctrl+D`） |
| **Rename** | 重命名 |
| **Delete** | 删除（选中后也可按 `Delete`） |

- 拖拽请求和文件夹可以调整顺序，或拖到其他文件夹中。
- 在顶部搜索框中输入，按名称或 URL 过滤集合树；底部 **Find** 面板也可以按名称或 URL 查找请求并打开。

从集合中打开请求时，会展开它所在的集合和文件夹并选中它。

## 和工作流的关系

工作流的 Existing Request 步骤引用集合中的请求。请求被删除后，引用它的步骤会提示需要重新选择；通过 AI 删除时，结果中会列出受影响的工作流。
