# Console 和历史

## Console

底部面板的 **Console** 记录每次实际发出的请求，包括在编辑器中发送的、工作流运行的和 AI 通过 MCP 发送的。点开一条记录可以看到：

- 实际发出的 URL、请求头和请求体（变量已替换）；
- 响应的状态码、响应头和响应体。

JSON 和 XML 请求体、响应体旁有格式化按钮，可以在格式化和原文之间切换，复制按钮复制当前显示的内容；也可以横向展开较宽的内容。点击 **Clear** 清空。

Console 保留最近 2 周的记录，最多 100 条；每条记录的请求体和响应体各最多保存 256 KB。请求体和响应体保存在单独的文件中，展开记录时才读取。

底部面板的 **Find** 按名称或 URL 查找集合中保存的请求，点击结果打开请求。

## 历史

侧边栏 **History** 按日期分组（Today、Yesterday 和更早的日期）列出发送过的请求，显示方法、URL 和状态码：

- 双击一条记录，把当时的请求在新标签页中打开为一个未保存的请求，可以修改后重新发送或保存。
- 顶部搜索框按 URL 或方法过滤历史记录。
- 点击清空按钮清除全部历史。

历史同样保留最近 2 周、最多 100 条。
