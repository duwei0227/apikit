# Collections

Collections organize your saved requests, with folders nested as deep as you like. **Collections** in the sidebar shows all of them.

![Collection tree](/screenshots/collections.png)

## Create and save

- Click **New Collection** to create a collection.
- The first time you click **Save** for a new request, choose the collection and folder to save it in; select the collection itself to save at its top level (shown as **(collection root)**). The dialog starts at the location you last saved to, or at the only collection when there is just one, and **New Collection** in the dialog creates a collection right there.
- Right-click a collection or folder: **Add Request** creates a request, **Add Folder** creates a folder.

## Organize

Right-click in the collection tree to open the menu.

**Collections and folders**:

| Action | Description |
|--------|-------------|
| **Add Request** / **Add Folder** | Create a request or folder inside it |
| **Move Up** / **Move Down** | Folders only: move it up or down within its level |
| **Duplicate** | Copy it, with its folders and requests (or press `Ctrl+D` when selected) |
| **Rename** | Rename it |
| **Import** / **Export** | Import or export; see [Import and Export](./import-export) |
| **Delete** | Delete it together with its requests (or press `Delete` when selected) |

**Requests**:

| Action | Description |
|--------|-------------|
| **Open** | Open it |
| **Move Up** / **Move Down** | Move it up or down within its level |
| **Move to...** | Move it to another collection or folder, at the end |
| **Duplicate** | Copy it (or press `Ctrl+D` when selected) |
| **Rename** | Rename it |
| **Delete** | Delete it (or press `Delete` when selected) |

- Drag requests and folders to reorder them or to move them into other folders.
- Type in the search box at the top to filter the collection tree by name or URL; the **Find** panel at the bottom also finds requests by name or URL and opens them.

When a request is opened from somewhere else, its collection and folders are expanded and it is selected.

## Collections and workflows

The Existing Request steps of a workflow refer to requests in collections. When a request is deleted, steps that use it ask you to choose another request; when the AI deletes it, the result lists the affected workflows.
